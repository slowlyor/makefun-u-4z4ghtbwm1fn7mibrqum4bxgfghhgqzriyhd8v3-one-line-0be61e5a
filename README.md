## The entry

> I asked AI to write my dating profile; now strangers reject me at machine speed.

## How it works

`main.py` writes one original funny line (80 characters) to `/output/entry.txt`.
Run it with:

```sh
python3 main.py
```

The output is deterministic: two runs produce byte-identical files.
